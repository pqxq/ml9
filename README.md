# Миколаївський ліцей №9

Сайт і система керування вмістом Миколаївського ліцею №9.

## Розробка

Проєкт побудований на Django та Wagtail. Основні розділи винесені в окремі Django-застосунки:

- `home` — головна сторінка та інформаційні сторінки;
- `news` — новини;
- `gallery` — фотогалерея;
- `staff` — педагогічний колектив;
- `schedule` — розклад;
- `admissions` — вступна форма;
- `documents` — публічні документи;
- `search` — пошук по сайту;
- `core` — спільні моделі, налаштування та службова логіка.

Глобальні шаблони розташовані в `mcl_site/templates/`, стилі та скрипти — у `mcl_site/static/`.

## Локальне середовище

Для роботи потрібні Python, встановлені залежності з `requirements.txt` і локальна база даних.

Основні команди:

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Адреси локального сайту:

- сайт — `http://localhost:8000/`;
- адміністративна панель Wagtail — `http://localhost:8000/admin/`.

Перевірка конфігурації:

```bash
python manage.py check
```

Тести:

```bash
python manage.py test
```

Після змін у моделях:

```bash
python manage.py makemigrations
python manage.py migrate
```

## Вміст сайту

Контент редагується через адміністративну панель Wagtail. Шаблони конкретних розділів зберігаються у відповідних застосунках, а спільний макет сайту — у `mcl_site/templates/base.html`.

Перед змінами в інтерфейсі варто перевірити каскад стилів у `mcl_site/static/css/style.css`: файл містить стилі для всіх основних розділів сайту та адаптивних станів.
